# @isptec/desktop (Fase 4)

Cliente **Desktop** (Electron) que embrulha o build da app Web (`apps/web`).
Satisfaz o requisito de **cliente multiplataforma** (Windows/Linux/macOS).

- **Dev:** Electron carrega `http://localhost:5173` (servidor Vite da Web).
- **Prod:** Electron carrega os ficheiros estáticos de `apps/web/dist`.

> A implementar na **Fase 4** do [plano-mestre](../../docs/00-plano-mestre.md).
