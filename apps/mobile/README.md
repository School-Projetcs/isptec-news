# @isptec/mobile (Fase 4)

Cliente **Mobile** (Expo / React Native + TypeScript).
Satisfaz o requisito de **cliente multiplataforma** (Android/iOS).
Reutiliza tipos e validação de `@isptec/shared`.

Funcionalidades-alvo: login, feed de notícias, reprodução multimédia (streaming),
upload, download e reprodução **offline**.

> A implementar na **Fase 4** do [plano-mestre](../../docs/00-plano-mestre.md).
